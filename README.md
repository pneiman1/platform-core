# platform-core

Shared infrastructure for vertical analytics products (DermIQ, BrewIQ, FitIQ, etc.).

This repo is a Python library + reusable assets. It is **not** a deployable application on its own. Each vertical product imports from this library and adds vertical-specific dbt models, Airflow DAGs, seed data, and branding.

## Status

Early development. Not yet versioned.
